# Assignment 1 - Basic Loading and Transformation

This assignment uses a movie dataset containing approximately 5,000 films released between 2000 and 2025.

The analysis focuses on the question:

**Which movie genre tends to perform best at the box office?**

The original dataset was reduced to a smaller set of relevant variables, including movie title, release year, genre, IMDb rating, budget, and box office revenue. The data was then transformed in R to compare average box office revenue across genres.

## Files

- `assignment_01_movie_box_office.Rmd` - R Markdown file containing the analysis
- `movies.csv` - Source movie dataset
